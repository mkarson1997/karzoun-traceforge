# Support

TraceForge is currently an engineering preview.

Public repository issues may be used for reproducible non-sensitive bugs, documentation defects,
and feature requests. Do not place vulnerabilities, credentials, private telemetry, or customer
data in public issues; follow SECURITY.md instead.

No uptime SLA, guaranteed response time, managed-operation commitment, or regulatory/compliance
commitment is provided by the public repository.

Customer-specific support terms, escalation paths, supported versions, maintenance windows, and
response targets should be defined in a separate commercial agreement when offered.
